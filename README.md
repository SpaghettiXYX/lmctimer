# Test and Exam Clock

A clean analog exam clock built for exam halls (e.g. Seewo whiteboards in landscape mode).

## Features

- **Analog-only clock** — Canvas-rendered, no digital countdown overlaid on the face
- **Scrollable duration picker** — iOS-style wheel, 15 min steps from 15 min to 5 hr
- **One-tap start** — records start time and calculated end time
- **Airbus takeoff chime** — three-tone seatbelt chime plays when the exam ends
- **Apple Time Server sync** — clock synced to `time.apple.com` (via macOS system clock + network offset)

## Usage

Open `index.html` in any browser. Set the subject and duration, then tap **Start**.
